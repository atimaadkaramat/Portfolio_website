# Portfolio Website

This repository contains my **Portfolio Website**, built as part of my **CS50 (Introduction to Computer Science)** coursework. The site showcases my personal projects, provides information about me, and includes a contact form for visitors.

## Live Demo

The website can be viewed live at:  
**https://atimaadkaramat.github.io/Portfolio_website/**

## 📌 Overview

This portfolio website is a static web project built using **HTML, CSS, and JavaScript**. It was developed to demonstrate:

- Responsive web design
- Navigation structure
- Project showcase
- Interactive elements (like the contact form)

This website was completed as part of the CS50 final project requirements.

## 🧩 Project Structure

The main files and folders include:
```text
├── images/ # Images used on the website
├── index.html # Homepage
├── about.html # About Me page
├── projects.html # Projects showcase page
├── contact.html # Contact form page
├── script.js # JavaScript for interactive behavior
├── styles.css # Custom styles
└── specification.txt # Project specification / assignment description
```

## 🚀 Features

- Clean navigation between pages  
- Portfolio/project listing  
- Contact form for visitor messages  
- Responsive layout using CSS  
- Simple JavaScript interactions  

## 🛠 Technologies Used

- **HTML5** – Structure and content  
- **CSS3** – Styling and layout  
- **JavaScript** – Logic and interactivity  

## 🧠 How It Works

1. **Navigation:** The navigation bar routes between pages (`index.html`, `about.html`, `projects.html`, `contact.html`).  
2. **Contact Form:** The form in `contact.html` can be connected to a backend or service (e.g., form submission service) to collect messages.  
3. **JavaScript:** `script.js` contains basic scripts for dynamic behavior, such as page interactions.
